# Moldova Climate Innovators

Разработай мне сайт

Для команды Made in Moldova, которая участвует в Oxford Said Global Climate Tech Challenge и состоит из 4 участников. Решение команды называется AgroHelp; сайт содержит ссылку на рабочий прототип.

Также на сайте должно быть окно с нашим видео на ютубе, а также отдельная страница для интервью
